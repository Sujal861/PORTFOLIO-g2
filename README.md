# 🤖 Robotic Portfolio Website

A sleek, responsive personal portfolio website built with Next.js, TypeScript, and Tailwind CSS — featuring a modern "robotic" design aesthetic powered by shadcn/ui components and Framer Motion animations.

*Automatically synced with [v0.dev](https://v0.dev) deployments.*

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) 18+
- [pnpm](https://pnpm.io/installation) (recommended, based on the included lockfile)

### Installation

```bash
# Clone the repository
git clone https://github.com/Sujal861/PORTFOLIO-g2.git
cd PORTFOLIO-g2

# Install dependencies
pnpm install
```

### Development

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.

### Build & Production

```bash
pnpm build
pnpm start
```

### Linting

```bash
pnpm lint
```
